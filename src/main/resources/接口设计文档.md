deviceStatus：整机设备运行总状态
sensorStatus：拆分各个传感器独立状态，便于识别单个探头损坏
envData：环境监测核心采集数据，字段命名统一驼峰，后端 Java 实体映射零成本
extend：扩展预留：后续可加电池电压、信号 RSSI、固件版本等

指令下达
{
"header": {
"msgType": "DOWN_CMD",
"requestId": "89b7d211-3c6e-4129-b152-78ac621f9012",
"deviceId": "esp32-S3-001",
"timestamp": 1755623400100,
"timeout": 5000
},
"payload": {
"cmdCode": "device_restart",
"params": {}
}
}

requestId：指令唯一 ID，设备回执必须原样带回，异步应答匹配核心
timeout：指令超时时间 ms，超过未回执云端判定指令失败
cmdCode：指令编码，统一枚举：
device_restart：设备重启
sensor_calibrate：传感器校准
light_switch：外接灯光开关

-----------------------------------------redis设计---------------------------------------------
{userId}:{deviceId}:latest 存设备最新数据  TTL：24h（长时间无上报自动过期，判定设备离线）eg  admin:esp32-s3-001:latest：
    {
    "deviceId": "esp32-S3-001",
    "deviceStatus": 1,
    "tempAht": 27.11,
    "tempBmp": 28.25,
    "humidity": 62.10,
    "pressureHpa": 990.20,
    "altitude": -27.34,
    "aht20Status": 1,
    "bmp280Status": 1,
    "timestamp": 1755623345216
    }

{userId}:deviceOnlineCount 在线设备总数 设备上线 INCR，设备掉线 DECR  ；Redis String 数字
    设备首次正常上报 / 重新上线：INCR admin:deviceOnlineCount
    设备离线（LWT 触发 / Key 过期）：DECR admin:deviceOnlineCount
    特性：Redis 单线程原子操作，不会出现并发计数错乱。


ws:device:router:{userId}:{nodeId}   WebSocket 客户端心跳会话存储（多端登录、连接保活）eg  ws:device:router:admin:web_192.168.1.100_chrome01
